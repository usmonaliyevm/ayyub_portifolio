Mijoz logotiplari shu papkaga qo'yiladi. SVG yoki shaffof fonli PNG, bo'yi 80–120 px yetarli.

Keyin `src/content/site.ts` dagi `clients` ro'yxatiga qo'shing:

```ts
export const clients = [
  { name: "Kompaniya", logo: "kompaniya.svg", url: "https://kompaniya.uz" },
];
```

Ro'yxat bo'sh bo'lsa "Men haqimda" bo'limida logotiplar qatori ko'rinmaydi.
