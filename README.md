# ayyub_portifolio

Muhammadayyub Usmonaliyev portfolio sayti: Flutter dasturchi va video montajchi. Next.js, TypeScript, uz/en.

## Ishga tushirish

```sh
npm install
npm run dev
```

http://localhost:3000

## Kontentni o'zgartirish

Hamma matn, loyihalar, videolar va aloqa ma'lumotlari bitta faylda: `src/content/site.ts`.

- `site.telegram`, `site.email` ni o'zingizniki bilan almashtiring
- `projects` ga yangi loyiha qo'shing
- `cuts` ro'yxatidagi fayllarni `public/videos/` ga joylang

## Deploy

Vercel: repo'ni ulang, boshqa sozlash kerak emas.
